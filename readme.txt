Stock Manager for WooCommerce allows admins to manage product stock in bulk, including setting stock status, quantities, and category-based stock changes.

== Description ==

Stock Manager for WooCommerce is a simple but powerful plugin that helps you manage product stock efficiently. Features include:

* Bulk update stock status (Stock In/Out)
* Category-based stock management
* Individual product stock status update
* Scheduling the stock update for a specific date and time

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/stock-manager/` directory, or install the plugin through the WordPress Plugins screen.
2. Activate the plugin through the ‘Plugins’ screen in WordPress.
3. Go to WooCommerce > Settings > Stock Manager to configure.
