Stock Manager for WooCommerce

Version: 1.1

1. Introduction

Stock Manager for WooCommerce is a powerful plugin that allows store owners to manage stock statuses efficiently. It provides an easy-to-use interface to apply stock-in or stock-out statuses globally, for specific products, or for specific categories. Users can also schedule stock status updates using date and time fields.

2. Installation

  1. Go to WordPress Admin > Plugins > Add New.
  2. Click Upload Plugin and select the plugin ZIP file.
  3. Click Install Now and then Activate.
  4. Click Settings to redirect to the setting page of the plugin.

3. Features

  • Stock Status: A dropdown to choose stock status.
  • All Products: A checkbox to apply stock-in or stock-out status to all products.
  • Selected Products: A dropdown field allowing users to apply stock-in or stock-out status to specific products.
  • Selected Categories: A dropdown field to apply stock-in or stock-out status to products in selected categories.
  • Schedule Stock Management: A checkbox to enable scheduling for stock status updates.
  • Stock Schedule Date: Users can schedule stock-in or stock-out status update for specific date
  • Stock Schedule Time: Users can schedule stock-in or stock-out status update for specific time

4. Usage Instructions

4.1 Updating Stock Status

  1. Go to WooCommerce > Settings > Stock Manager.
  2. Select either:
    • Stock Status: Select a stock status ( In Stock / Stock Out) to apply stock status changes.
    • All Products: Check to apply to all products.
    • Selected Products: Choose specific products from the dropdown.
    • Selected Categories: Choose categories to apply stock status changes.
  3. Click Save Changes to apply the stock status.

4.2 Scheduling Stock Status

  1. Enable the Scheduled Stock Status checkbox.
  2. Set the Date for the scheduling the stock update on the specific date.
  3. Set the Time for the scheduling the stock update for specific time on the selected date. If the time is empty or not selected then stock status will be change on 23:59 on the selected date.
  4. Click Save Changes to schedule the update.
